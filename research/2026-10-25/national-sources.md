Researched 2026-10-25. VERIFIED = I fetched the official/vendor page or queried the live API/data today. UNVERIFIED = search snippet, vendor claim, or my estimate. Web-search budget ran out near the end; the items marked UNVERIFIED-budget could not be re-checked.

## TL;DR ranking (details per source below; final table at bottom)
1. **FMCSA Company Census (data.transportation.gov az4n-8mr2)** — free Socrata API + daily refresh, `COMPANY_OFFICER_1/2`, `EMAIL_ADDRESS`, `PHONE`, `CELL_PHONE`, `DBA_NAME`. 4.52M rows, 2.24M active, 94% of active rows have an officer name (VERIFIED by live count queries). Covers trucking/towing/moving/dump/landscapers-with-trucks/any company with a USDOT number. Best owner source in this list for its niche.
2. **CMS NPPES** — free monthly full file (~1 GB zip) + weekly incrementals + free query API; Type-2 org records carry `Authorized Official First/Last/Middle Name`, `Authorized Official Title or Position`, `Authorized Official Telephone Number` (VERIFIED in readme + live API). Covers every healthcare org that bills (dentists, chiros, PT, med spas with an NP/MD, pharmacies, optometrists, mental health). Caveat: CMS download site shows "down for maintenance until further notice" today (VERIFIED); API still up.
3. **SBA PPP FOIA** — free CSVs (13 files, 240930 vintage), `BorrowerName`, `BorrowerAddress`, `BusinessType`, `NAICSCode` (VERIFIED). In a 900k-row sample 35.9% of loans are Sole Proprietorship / Self-Employed / Independent Contractor, where BorrowerName is a person name (VERIFIED computed). Match key = name+address; no person field for LLC/corp borrowers.
4. **BBB profiles** — "Business Management: Mr. James Lee Smith, Owner" / "Principal Contacts" / "Customer Contacts" with honorific+name+title (VERIFIED on a live profile). High fill rate on accredited + many non-accredited trades. ToU: personal non-commercial use, no aggregation, no "sales and marketing purposes" (VERIFIED). Serper `site:bbb.org "<name>" <city>` returns the profile; snippet usually contains the principal.
5. **SAM.gov Public V2 extract** — free monthly+daily zips; `GOVT BUS POC FIRST NAME / LAST NAME / TITLE`, ALT GOVT BUS POC, PAST PERF POC, ELEC BUS POC (VERIFIED in layout PDF). Only ~1M registrants, mostly gov contractors; low overlap with Maps SMBs.
6. **Google Maps itself** — no owner-name field. Outscraper `owner_title` = the GBP display name (business name in both vendor samples, VERIFIED); Apify compass actor exposes `ownerUpdates`, `ownerDescription`, `responseFromOwnerText`, `claimThisBusiness` but no owner name (VERIFIED output schema). Owner-reply signatures ("- Mike, Owner") are a text-mining opportunity, not a field.
7. **IRS 990 / ProPublica** — nonprofits only; officer names are in e-file XML (free bulk from IRS, VERIFIED page) and shown on ProPublica org pages ("Key Employees and Officers", VERIFIED), but NOT in the ProPublica API JSON (VERIFIED: only `compnsatncurrofcr` fields).
8. Everything else (D&B free pages: one "Key Principal" per company VERIFIED; Alignable: person-named profiles VERIFIED; Yelp: owner section not present on a claimed page VERIFIED; Bizapedia: paywalled VERIFIED; Manta/OpenCorporates/ZoomInfo/Nextdoor/FB transparency: UNVERIFIED or not useful; WHOIS ≈ 86% unidentifiable post-GDPR UNVERIFIED-2021 study; UCC bulk $600-3,000/state; Data Axle library terms forbid commercial use VERIFIED).

## 1. CMS NPPES NPI Registry (healthcare orgs)
- **What**: National Plan & Provider Enumeration System. Type 1 = individual providers, Type 2 = organizations. Every Type 2 record names an **Authorized Official** (the person who applied; for a small practice this is nearly always the owner/dentist/chiro or office manager).
- **URLs**: Bulk: https://download.cms.gov/nppes/NPI_Files.html — **VERIFIED today the page body is only "This site will be down for maintenance until further notice"** (fetched twice, curl + WebFetch). Program page: https://www.cms.gov/medicare/regulations-guidance/administrative-simplification/data-dissemination (VERIFIED: "Full Replacement Monthly NPI File, Weekly Incremental NPI File, and Full Replacement NPI Deactivation File"; zip contains Read Me, Code Values, Header File, "FOIA-disclosable NPPES health care provider data file"; CSV; "no charge"). Mirror with readme + older full files: https://data.nber.org/npi/ (VERIFIED readme download). Query API: `https://npiregistry.cms.hhs.gov/api/?version=2.1&enumeration_type=NPI-2&organization_name=...&state=..&limit=200` (VERIFIED live call; free, no key).
- **Exact fields (VERIFIED from NPPES_Data_Dissemination_Readme.pdf, Exhibit 2-1)**: `Entity Type Code` (1/2), `Provider Organization Name (Legal Business Name)`, `Provider Other Organization Name` (DBA), `Provider Business Practice Location Address …`, `Provider Business Practice Location Address Telephone Number`, `Authorized Official Last Name`, `Authorized Official First Name`, `Authorized Official Middle Name`, `Authorized Official Title or Position`, `Authorized Official Telephone Number`, `Authorized Official Name Prefix Text`, `Authorized Official Name Suffix Text`, `Authorized Official Credential Text`, taxonomy codes 1-15. API JSON keys (VERIFIED): `authorized_official_first_name`, `authorized_official_last_name`, `authorized_official_title_or_position`, `authorized_official_telephone_number`.
- **Bulk**: monthly full zip ≈1,032 MB (Sept 2025 listing, UNVERIFIED-snippet), ~3 GB CSV uncompressed (NBER, UNVERIFIED), weekly incrementals 6–12 MB. Free. Record counts: total NPIs ≈8M+, Type 2 ≈1.6–1.8M (UNVERIFIED — could not fetch counts while site is down).
- **Match keys**: org name (legal or DBA/"Other Organization Name"), practice address + phone (practice-location phone matches Maps phone very often), taxonomy filters (dentist 1223*, chiro 111N*, PT 2251*, pharmacy 3336*, optometry 152W*). Vets: not in NPPES (no NPI).
- **Terms**: FOIA-disclosable, no restriction; CMS note "no way to opt out" (VERIFIED). Title field is free text ("Owner", "President", "Office Manager", "Agent", "DDS").
- **Realistic share of Maps SMBs named**: ~0% of non-health verticals; for dental/chiro/PT/pharmacy/optometry/med-spa-with-NPI 70–90% of listings match a Type 2 record and ~60–75% of those authorized officials are the owner (rest = office manager/billing/credentialing agent; filter on title words). Effort: low (one CSV load; or live API at <1s per query).

## 2. FMCSA Motor Carrier Census (USDOT registrants)
- **What**: Every entity with a USDOT number (interstate carriers, intrastate HM, many intrastate-only states register too). Includes for-hire and private carriers — landscapers, plumbers, HVAC with >10,001 lb trucks, movers, towing, dump, junk removal, ag haulers.
- **URLs**: Program page https://www.fmcsa.dot.gov/registration/fmcsa-data-dissemination-program (VERIFIED via Apify fetch; Akamai blocks datacenter curl/WebFetch with 403): "shares the FMCSA regulated entity census … at no charge", "updated daily from a 24-hour old database", census "contains … identifying data, business operations, carrier review, equipment, and driver data". Dataset: **Company Census File, data.transportation.gov id `az4n-8mr2`** (VERIFIED; `rowsUpdatedAt` 2026-10-24). Socrata SoQL endpoint `https://data.transportation.gov/resource/az4n-8mr2.json` (VERIFIED live). Also SMS monthly "Motor Carrier Census Information" file (contacts, email, phone; VERIFIED description).
- **Exact fields (VERIFIED columns.json)**: `DOT_NUMBER`, `LEGAL_NAME`, `DBA_NAME`, `PHY_STREET/CITY/STATE/ZIP/CNTY`, `CARRIER_MAILING_*`, `PHONE`, `FAX`, `CELL_PHONE`, `EMAIL_ADDRESS`, **`COMPANY_OFFICER_1`, `COMPANY_OFFICER_2`** (names only, no title field), `BUSINESS_ORG_DESC` (sole prop/LLC/corp), `POWER_UNITS`, `TOTAL_DRIVERS`, `CARRIER_OPERATION` (A interstate / B intrastate HM / C intrastate non-HM), `STATUS_CODE` (A/I), `MCS150_DATE`, `DUN_BRADSTREET_NO`, cargo flags (`CRGO_GENFREIGHT` …), `ADD_DATE`. 147 columns.
- **Live counts (VERIFIED 2026-10-25)**: 4,521,528 rows; 3,872,366 with officer_1; 2,242,834 active; **2,100,426 active with officer_1 (93.6%)**; 1,707,422 active with email (76%). Sample TX rows: `legal_name "ALBERT FRANKS", dba "SOUTH COAST TRUCKING", officer_1 "ALBERT L FRANKS", officer_2 "ANTHONY L FRANKS", power_units 2` — i.e., for 1–5 truck outfits officer_1 is the owner.
- **Bulk**: CSV export of the whole dataset from Socrata (free; ~1.5–2 GB UNVERIFIED size) or paged API (no key needed for light use; app token raises throttle). Daily refresh.
- **Match keys**: DOT number (if the Maps/website shows it), phone (PHONE/CELL_PHONE vs Maps phone is the strongest key), legal/DBA name + city + state. Note `power_units` is stored as text in Socrata (numeric compare fails — VERIFIED error).
- **Terms**: public; FMCSA disclaimer only. Email/cell are PII in practice — the file is public but outreach must still satisfy CAN-SPAM/TCPA.
- **Share named**: trucking/towing/moving/dump/junk: 80–90% of Maps listings match and officer_1 is the owner in most 1–10-unit companies. Across a general Maps SMB mix: ~5–8% (only companies with a USDOT number; many trades have one). Effort: low; already Socrata-queryable.

## 3. SBA PPP FOIA + 7(a)/504 FOIA
- **PPP**: https://data.sba.gov/dataset/ppp-foia (VERIFIED). 14 resources: `ppp-data-dictionary.xlsx`, `public_150k_plus_240930.csv`, `public_up_to_150k_1…12_240930.csv` (file 1 = 414 MB, 900,000 rows — VERIFIED download). Last modified Oct 21 2024 (page); data vintage 2024-09-30. **Header (VERIFIED)**: `LoanNumber, DateApproved, SBAOfficeCode, ProcessingMethod, BorrowerName, BorrowerAddress, BorrowerCity, BorrowerState, BorrowerZip, LoanStatusDate, LoanStatus, Term, SBAGuarantyPercentage, InitialApprovalAmount, CurrentApprovalAmount, UndisbursedAmount, FranchiseName, ServicingLender*, RuralUrbanIndicator, HubzoneIndicator, LMIIndicator, BusinessAgeDescription, ProjectCity, ProjectCountyName, ProjectState, ProjectZip, CD, JobsReported, NAICSCode, Race, Ethnicity, *_PROCEED, BusinessType, OriginatingLender*, Gender, Veteran, NonProfit, ForgivenessAmount, ForgivenessDate`. **No owner/officer field.**
  - **BusinessType distribution, file 1 (VERIFIED computed, n=900,000)**: Corporation 29.9%, **Sole Proprietorship 25.8%**, LLC 18.3%, S-Corp 10.8%, **Self-Employed Individuals 5.6%**, **Independent Contractors 4.5%**, Non-Profit 2.1%, Partnership 1.4%, LLP 0.6%, Single Member LLC 0.4%. → **35.9% of loans are person-named borrowers**; of those only ~6% (16,662/322,449) carry a business marker (LLC/INC/DBA/etc.), so ~34% of all PPP rows give a person name + street address + NAICS. 0 blank names in this file (SBA redactions of sole-prop names were lifted in Dec 2020).
  - Match: Maps business usually has a trade name; the PPP sole-prop row is in the person's name at the same address. So match on **address+ZIP (+NAICS)**, not name. Entity borrowers (64%) give no person.
  - Terms: FOIA release, no restrictions. Many lenders' PPP rows have the project address = home address.
  - Share named: for a Maps SMB list, roughly 30–45% of listings have *some* PPP row at the address; of those ~35% are person-named → **~10–15% of a general Maps list gets an owner name from PPP**, higher in sole-prop-heavy trades (cleaning, landscaping, barbers, handymen, trucking owner-operators), near zero for dentists/LLC-heavy trades. Data is 2020–21 so churn reduces it. Effort: medium (~10 GB CSV load; address normalization).
- **7(a)/504 FOIA**: https://data.sba.gov/dataset/7a-504-foia (VERIFIED). Files `FOIA_7a_FY1991_FY1999…FY2020_Present_asof_260630.csv`, `FOIA_504_FY1991_FY2009 / FY2010_Present_asof_260630.csv`, `7a_504_foia_data_dictionary.xlsx`. Quarterly. **Fields (VERIFIED dictionary)**: `BorrName, BorrStreet, BorrCity, BorrState, BorrZip, BankName, GrossApproval, ApprovalDate, NaicsCode, NaicsDescription, FranchiseName, BusinessType ("Individual, Partnership, or Corporation"), BusinessAge, JobsSupported, LoanStatus …`. No owner field; `BusinessType=Individual` rows are person-named (small share). Low yield (~2M loans total, mostly entities). Skip except for address-match bonus.
- **Other SBA datasets with owner names**: none found (SBA 8(a)/HUBZone DSBS has contact names but is a web app, not bulk — UNVERIFIED-budget).

## 4. SAM.gov Entity Management Public Extract
- **URLs**: data.gov listing https://catalog.data.gov/dataset/system-for-award-management-sam-public-extract-entity-registration (VERIFIED: "updated monthly", UTF-8 and ASCII zips; listing itself stale 2018). Current downloads live in SAM.gov → Data Services → Entity Registration → Public V2 (login-free, but the page is a JS app; WebFetch saw only "SAM.gov"). Layout PDF: https://open.gsa.gov/api/sam-entity-extracts-api/v1/SAM_Entity_Management_Public_V2_Extract_Layout.pdf (VERIFIED, v1.5 Dec 2019). Files: `SAM_PUBLIC_V2_MONTHLY_YYYYMMDD.ZIP`, `SAM_PUBLIC_V2_DAILY_YYYYMMDD.ZIP` (+UTF-8 variants). Also Entity API https://open.gsa.gov/api/entity-api (key required, free).
- **Person fields (VERIFIED layout)**: cols 47–50 `GOVT BUS POC FIRST NAME / MIDDLE INITIAL / LAST NAME / TITLE` (+ POC address), 58–61 `ALT GOVT BUS POC …`, 69–72 `PAST PERF POC …`, 80–83 `ALT PAST PERF POC …`, 91+ `ELEC BUS POC FIRST NAME …`. **Public extract has NO POC email/phone** (those are in the FOUO extract, UNVERIFIED-snippet). Entity fields: `LEGAL BUSINESS NAME`, `DBA NAME`, `PHYSICAL ADDRESS LINE 1…`, `ENTITY STRUCTURE`, `BUSINESS TYPE STRING`, `PRIMARY NAICS`, NAICS list, SBA certs.
- **Coverage**: entities registered to do federal business (~0.9–1.1M active, UNVERIFIED). Registrants may opt out of public display (`PUBLIC DISPLAY FLAG`). POC = usually owner at a small firm.
- **Share named**: 2–5% of a general Maps SMB list (higher for janitorial, IT, construction, consulting, trucking near bases). Effort: low–medium (fixed-width/pipe layout, monthly 1–2 GB).

## 5. BBB.org profiles
- **Live example (VERIFIED)** https://www.bbb.org/us/tx/lindale/profile/plumber/dixie-plumbing-co-1075-28090637: "Business Management: Mr. James Lee Smith, Owner"; "Principal Contacts: Mr. James Lee Smith, Owner"; "Customer Contacts: Mr. James Lee Smith, Owner"; address, phone, "Business Started 9/1/2012", accredited. Search snippets of other profiles show the same block incl. non-accredited (e.g., "Mr. Terry Tullius, Owner; Mrs. Sherry Tullius, Manager/Co-Owner", UNVERIFIED-snippet).
- **Coverage**: BBB claims ~5M+ profiles (UNVERIFIED); every business that ever got a complaint, a quote request or applied for accreditation. Trades/home services very well covered; restaurants/salons less. Reliability: BBB "does not verify the accuracy of information provided by third parties" (VERIFIED disclaimer), but the Business Management block comes from BBB's own intake or state filings, and it is the single highest-quality free owner+title string on the web for home-service SMBs.
- **Fields**: Business Management (name, title), Principal Contacts, Customer Contacts, Additional Contact Information, Business Started, Type of Entity, licensing numbers.
- **Access**: no bulk; profile pages render server-side; WebFetch worked from datacenter. Serper query `site:bbb.org "<business>" <city> <state>` → profile URL; Google snippet often includes "Business Management …". Volume: 1 Serper credit + 1 page fetch per business.
- **Terms (VERIFIED https://www.bbb.org/terms-of-use)**: content for "personal, non-commercial use", "not for sale, republication, or aggregation", may not "use the Sites to create, supplement, or compile data for any service", prohibited to "Use the Sites for sales and marketing purposes". Legal exposure is real for systematic scraping; using Google snippets reduces but does not eliminate it.
- **Share named**: 35–55% of Maps home-service listings have a BBB profile with a named principal; 15–30% for a general Maps mix. Effort: low (Serper + fetch), legal review needed.

## 10. IRS Form 990 / USPTO
- **990 (nonprofits: churches excluded, daycares, clinics, private schools, associations, chambers)**: IRS bulk e-file XML https://www.irs.gov/charities-non-profits/form-990-series-downloads — monthly zips 2019–2026 (VERIFIED page; no sizes given). ProPublica org page (VERIFIED) lists "Key Employees and Officers" with titles and states XML "Includes complete filing data (financial details, names of officers, tax schedules, etc.)"; pre-Oct-2021 data also on AWS. **ProPublica API** (VERIFIED live JSON for EIN 473186128): `filings_with_data` carries only financial elements (`compnsatncurrofcr`, `totrevenue` …) — **no officer names via API**; you must parse XML (Part VII element names `Form990PartVIISectionAGrp/PersonNm, TitleTxt` — UNVERIFIED-budget) or scrape the org page. Share of Maps SMBs: nonprofits are ~2–4% of a Maps mix; 990-N filers (<$50k) have no officer list. Effort: medium (XML parse) or free via ProPublica page scrape.
- **USPTO trademarks**: Case Files dataset owner table (VERIFIED vartable): `own_name`, `own_entity_cd` (legal-entity-type code; individual is one code), `own_addr_1/2`, `own_addr_city`, `own_addr_state_cd`, `own_addr_postal`, `own_altn_name` (DBA/AKA). Free bulk (daily XML + annual OCE Stata/CSV). Only trademarks registered by individuals name a person; SMBs rarely register. Share: 1–3%. Effort: medium-high for the yield; skip.

## 11. UCC filings
- State-run, no national free file. Prices seen: **Texas** (VERIFIED https://direct.sos.state.tx.us/help/help-ucc.asp?pg=bulk): Master Unload $1,150 (previous) / $1,350 (new), daily update $65/day data; fixed-width TXT; fields debtor name+address, secured party, filing/expiration, collateral; several GB. **Kentucky** $1,500/mo commercial; **Indiana** $3,000 one-time / $425 weekly; **Maine** $600 monthly; **Illinois** $2,500 + $200/wk (all UNVERIFIED-snippet from state pages). UCC-1s for equipment loans list the LLC *and* the owner as co-debtors (personal guarantee) — a genuinely good owner signal for trades that finance trucks/equipment, but cost is per state and the individual-vs-org flag varies. Free alternative: some states expose UCC search online with debtor names (TX, FL, CA UCC Connect) — per-lookup, slow. Verdict: buy only for 2–3 priority states if the SOS route is weak there.

Cheap enough ($2–5/1k) to run as a late-stage tier on domains still unnamed; treat as low-confidence.

## Top surprises
1. **FMCSA census is a near-complete owner file for trucking/towing/moving**: 2.1M active carriers with officer names, 1.7M with email, cell phone column, daily refresh, free SoQL API — better than any SOS file for that vertical.
2. **CMS NPPES bulk download page is currently "down for maintenance until further notice"** (both fetches today); the query API and NBER mirror still work, so build on the API/mirror.
3. **Google Maps has no owner-name field at all** — Outscraper's `owner_title` is just the GBP display name (business name in every sample), and Apify's `ownerUpdates/ownerDescription/responseFromOwner*` are text blobs; the Apify "Business leads enrichment" add-on ($3–5/1k) is a LinkedIn-style people DB, not Maps data.
4. **PPP: 36% of loans are person-named** (sole prop 25.8%, self-employed 5.6%, IC 4.5% in a 900k sample) with street address + NAICS — a free address-keyed owner source for sole-prop trades that nobody in the pipeline uses yet.
5. BBB and D&B both publish a named principal with title on free pages, but both ToU forbid aggregation/commercial use; Data Axle library access is explicitly noncommercial-only.
